# Frontend

React + TypeScript + Tailwind CSS frontend, built with Vite.

- API requests use relative `/api` paths and are proxied to Django by Vite.
- Dev server is bound to `127.0.0.1:5173` (local only).
- Start from the project root with `scripts/start-frontend.sh`.

See the root `README.md` for the full setup and architecture notes.
